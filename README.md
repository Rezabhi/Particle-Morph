# ✨ Particle Morph

**Turn words into particles. Turn particles into art.**

Particle Morph is an interactive 3D particle experience built with JavaScript and Three.js. It transforms thousands of glowing particles into text, symbols, and beautiful animated shapes in real time.

Explore a dynamic particle universe where creativity meets technology.

## 🌌 Features

- **3D Particle System** – Thousands of glowing particles rendered in real time.
- **Text Morphing** – Transform particles into any custom word or number.
- **Persian & English Support** – Create particle-based text in both languages.
- **Interactive Mouse Effects** – Move your mouse over particles to push them away.
- **Touch Support** – Enjoy interactive particle effects on mobile devices.
- **Animated 3D Sphere** – A rotating and breathing particle sphere.
- **Color Gradients** – Multiple vibrant color combinations.
- **Ready-made Presets** – Try Hello, 2026, Persian text, hearts, and more.
- **Responsive Design** – Designed for desktop and mobile screens.
- **Reduced Motion Support** – Respects the user's motion preferences.

## 🚀 Getting Started

### 1. Clone the repository

```bash
https://github.com/Rezabhi/Particle-Morph.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd particle-morph
```

### 3. Run the project

Open `index.html` in your browser.

No build tools or package installation required.

**Note:** An internet connection is required to load the external libraries and fonts.

## 🎮 How to Use

1. Open the project in your browser.
2. Enter a word, name, or number.
3. Click the **Create** button.
4. Watch the particles transform into your text.
5. Move your mouse or finger over the particles to interact with them.
6. Click the sphere button to return to the 3D sphere.
